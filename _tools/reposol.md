A full-stack, browser-based OSCAL workbench built with React and FastAPI.
Features visual catalog and profile editors with an interactive document tree,
profile resolution engine, parameter inheritance, and a unified control editor.
Supports document management across all OSCAL lifecycle stages, official NIST
schema validation, and multi-format import/export (JSON, YAML, XML).
